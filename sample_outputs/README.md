# Sample execution evidence

These are outputs generated by executing the local Python/SQLite pipeline.

- `edge_case_run_report.json`: a 20-row edge-case batch report with nine stage results, reject-reason counts, run metrics and reconciliation.
- `accepted_records_sample.csv`: accepted target records with `source_file` and `run_id` lineage.
- `rejected_records_sample.csv`: rejected raw records with source row numbers and reasons.
- `anomaly_comparison_report.json`: a later batch compared with a baseline, showing explainable null-rate and status-distribution alerts.

Expected-answer labels for the edge-case generator are stored in a separate `.manifest.json` sidecar, never in the source business data.
